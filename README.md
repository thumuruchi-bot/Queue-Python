# Queue (Python)

## Description
A simple Python program demonstrating Queue operations using a list.

## Features
- Enqueue Operation
- Dequeue Operation
- Front Element
- Display Queue

## Technology Used
- Python
- List
- Queue

## Output
Queue after Enqueue: [10, 20, 30]
Dequeued Element: 10
Front Element: 20
Current Queue: [20, 30]
